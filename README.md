# 🦁 Sbe3 vs Charlomanti: The Primal War 🐆

An interactive retro-arcade fighting arena game and web experience built with HTML5, Tailwind CSS, procedural SVG graphics, and Web Audio API sound synthesis.

![Game Banner](preview.png)

## ⚔️ The Fighters

### 🦁 Sbe3 (The Lion Sovereign)
- **Power**: Solar desert lion power with overwhelming royal charisma.
- **Abilities**:
  - `Lion Claw Strike` (`[A]`): Fast, razor-sharp melee slash.
  - `Royal Roar` (`[S]`): Concussive soundwave that stuns and blasts opponents back.
  - `Alt Ego Shift` (`[D]`): Awakens the dark shadow-lion spirit with a purple flaming aura and glowing red eyes, boosting Attack by **+60%**.
  - `CHARISMA ULT` (`[F]`): Solar beam ultimate with full-screen cinematic freeze-frame: *"Bow to the King's Charisma!"*

### 🐆 Charlomanti (The Jaguar Huntress)
- **Power**: Ancient rainforest predator agility and shadow camouflage.
- **Abilities**:
  - `Jaguar Pounce` (`[H]`): Leaping dive strike from above.
  - `Law Doc Hits` (`[J]`): Signature 3-hit rapid low dock sweep combo attacking the ankles.
  - `Shadow Camouflage` (`[K]`): Enters stealth stance, mitigating incoming damage and setting up counters.
  - `APEX JAGUAR ULT` (`[L]`): Phantom shadow claws shredding through space.

---

## 🎮 Modes of Play
1. **Play as Sbe3 (vs CPU)**: Control Sbe3 with `[A, S, D, F]` against intelligent AI Charlomanti.
2. **Play as Charlomanti (vs CPU)**: Control Charlomanti with `[H, J, K, L]` against CPU Sbe3.
3. **War Simulation (Auto Spectator)**: Sit back and watch both beasts duel autonomously!
4. **2-Player Local Duel**: Two players face off on the same keyboard in real-time.

---

## 🔊 Sound Design
Built with the Web **AudioContext API**—no external audio files or internet connection required for sounds:
- Procedural punch impacts
- Lion roar modulation
- Low dock kick whoosh sweeps
- Golden royal ultimate fanfare
